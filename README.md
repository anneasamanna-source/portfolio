# Anneasa Manna — Portfolio (Next.js)

```
npm install
npm run dev   # http://localhost:3000
```

- Projects & images: `public/portfolio.js` (top, `P` array). Put files in `public/images/` and set `img:"/images/name.jpg"`.
- Text/sections: `components/markup.ts`
- Styles: `app/globals.css`
- Cartoon icons & jokes: `IC` and `SAY` in `public/portfolio.js`
